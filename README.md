# 佐藤（2019）世代会計の再現（2010年基準）

佐藤康仁「消費税率引き上げ延期に伴う財政負担に関する世代会計分析」（東北学院大学経済学論集 第191号）の表2〜4を、公開データだけで組み直したもの。

## 実行

```
cd src
PYTHONPATH=. python3 ga_model.py      # 3ケースの世代会計（負担・受益・純負担）
PYTHONPATH=. python3 compare.py head  # 論文表2との比較・延期効果 → ../out_*.csv
PYTHONPATH=. python3 variants.py      # 前提を変えた感応度 → ../out_variants.csv
PYTHONPATH=. python3 gap_sensitivity.py  # 40〜60歳のズレの感応度（賃金・年金改革）→ ../out_gap_sensitivity.csv
PYTHONPATH=. python3 validate.py     # 年齢を隠す検証・表3/表4での検証 → ../out_validation_*.csv/json
python3 make_manifest.py --check      # raw/ のデータが manifest.json の SHA-256 と一致するか照合
python3 chart.py                      # 比較グラフ → ../ga_replication.png
```

取得済みデータは `raw/` に同梱しているので、再計算だけならネット接続は不要。
（`src/es.py` はデータ再取得用の e-Stat API ヘルパーの読み込み口で、実行環境依存。再計算には使わない）

依存：`pip install -r requirements.txt`

## 主な前提（論文に明記がなく推定したもの）

- 世帯主年齢の世帯値を本人年齢として20歳以上に帰属（子どもには帰属しない）
- 勤め先収入：勤労者世帯の有業者1人当たり × 2010国勢調査の年齢別雇用者率
- 全消の収入は勤労者・無職世帯のみ表章 → 世帯数ウェイトで全世帯値を合成
- 固定資産税 8.8649兆円（東京都税制調査会資料の2010年度全国値）、所得税等は家計支払分＝労働分・残り＝資本分
- 現物社会移転55.2兆円を付表7（機能別支出）で医療31.2兆・教育12.0兆・その他11.9兆に分割（論文表1の3分類）。教育は受益に入れず G（政府消費）に含める（論文脚注7）
- G＝集合消費＋教育＋公的純投資＋その他資本移転（純）、一人当たりで g 成長
- 年金改革：保険料率 18.3%へ段階引上げ、マクロ経済スライド 年0.9%（2015〜2043）、報酬比例部分の支給開始年齢引上げ
- 2011〜14年の人口は2010国勢調査と2015推計の線形補間、2116年以降は年齢別変化率で外挿

## 40〜60歳のズレの検証（gap_sensitivity.py）

- （2026-10-13時点の数値。3分類への変更後は平均ズレ−714万円が基準）年金改革（スライド率・期間、支給開始年齢、保険料率）を最大限変えても、40〜60歳の平均ズレ（−624万円）は約110万円しか縮まらない
- 賃金を世帯単位（世帯主年齢）にすると約150万円縮まる
- 介護給付を実態どおり高齢者に配分（`CARE_MODE="age"`）すると、ズレは逆に−784万円へ拡大し、潜在的債務は約165兆円増える。論文は表1のとおり「社会保障給付−公的年金給付」で配分しており、介護給付の多くが子育て世帯に乗っている可能性が高い。既定値は論文どおり（`CARE_MODE="ss_other"`）

## 改訂履歴メモ

- 2026-10-14：GPT版の実装（別途作成）との比較で、現物社会移転の分け方を見直し。以前は「個別的非市場財18.0兆円」を全額教育とみなして G に入れていたが、付表7では教育は12.0兆円で、残り6.0兆円は社会保護・文化等だった。3分類に直すと不均衡は605.5%→655.5%、0歳世代の純負担は1,173万円→1,081万円（論文1,023万円）。以前の605.5%の一致は、この分類の誤りに一部助けられていた
- 固定資産税を実数（8.8649兆円）に変更。消費税率の暦年按分（`VAT_CALENDAR`）も試したが結果はほぼ不変

## 検証（validate.py、GPT版の作法を移植）

**表3・表4での検証**：モデルも前提選びも表2しか見ていないので、延期（表3）と8%据え置き（表4）は手付かずの検証データ。基本ケースからの変化幅を比べた。

| 指標 | 論文 | 再現 |
|---|---|---|
| 延期：年齢別変化の相関 | − | 0.95 |
| 延期：最大軽減の年齢 | 45歳 | 45歳 |
| 延期：不均衡の変化 | +4.1pt | +4.05pt |
| 延期：潜在的債務の増加 | +10.7兆円 | +9.7兆円 |
| 延期：将来世代の増加 | +31.2万円 | +43.8万円 |
| 据置：年齢別変化の相関 | − | 0.99 |
| 据置：不均衡の変化 | +84.5pt | +86.3pt |
| 据置：潜在的債務の増加 | +107.2兆円 | +85.2兆円 |

制度変更の効果（変化幅）はよく再現できる一方、0〜10歳の延期効果は論文の1.5〜4.6万円に対して0（子どもに消費税負担を割り振っていないため）。

**年齢を隠す検証**：表2の半分の年齢だけで前提（48通り）を選び、残りの年齢で誤差を測った。2つの分割とも同じ前提（世帯主帰属・世帯単位の賃金）が選ばれ、検証誤差（310〜340万円）は学習誤差と同程度で、前提選びの過剰適合は見られない。世帯単位の賃金は、既定（有業者×雇用者率）より隠した年齢で約90〜100万円誤差が小さい。

**データ台帳**：`raw/manifest.json` に19ファイルの出典・取得条件・バイト数・SHA-256 を記録。
